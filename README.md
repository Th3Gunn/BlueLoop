BluePill devboard based project - ultra compact guitar loop switcher controlled entirely through MIDI TRS (something like Morningstar ML5R).
Includes 0.96" I2C LCD module, few buttons (only for programming), USB-C for flashing and USB MIDI. 
5 relay controlled loops (relays controlled with 74HC595 bit shift register), and discrete MOSFET input and  output mute circuit.

Future plans are to make completely custom board with everything on it and to create Windows application for preset programming.
